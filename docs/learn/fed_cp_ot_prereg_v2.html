Status (2026-11-03 ET): out-of-sample scoring is NOT authorized. Nothing out-of-sample has been run. v2 only fixes the rules before anyone looks. Full text: PREREG_v2_fed_cp_ot.md. Engineering spec: HARNESS_TICKET_v2.md. Review it answers: PR #20.

Why pre-register again?

A pre-registration is only worth something if every choice that could move the answer is fixed before the data is seen. The Quant review found choices that were still open: how to score a forecast that puts mass between the six maturity buckets, what the "gain" hurdle G means, and when data counts as known. Each could have been settled after peeking, so v2 settles them now. Where there was a choice, v2 takes the stricter one.

KumoRFM as a rival row

As learned on the KumoRFM-on-NIM page, a relational foundation model is a cheap, no-training rival. v2 adds it as a separate Family K with these rules:

  • Graph: 24 (type, bucket) entities, using the last 156 usable weeks as context.
  • Target: next week's share, as a regression. Negative predictions are clipped to zero and the shares renormalized.
  • Modes: best is the primary run; fast is descriptive only.
  • Tests: two one-sided tests (vs SEL, vs persistence), Holm-adjusted, with the same G bars as the other families.
  • Failures: if more than 5% of calls fail after retries, Family K is INCOMPLETE.

Kumo never enters the app or the model-selection pool.

Intervals (non-gating)

The app will show a 90% Wasserstein ball around its forecast. Its radius is the 90th-percentile realized loss over the past 156 usable weeks, which is split-conformal calibration on the past only. Coverage is reported, but no claim rests on it.

Honest caveats

  • Power: planning power to detect a 5% gain is only about 0.50 (K4 passed at 0.5015). A null result will be reported as "underpowered", not as "no gain".
  • Revisions: the historical run uses one late data vintage, so revisions are a disclosed pseudo-real-time limitation.
  • Error control: each family controls its own error rate, but no family-wise control across the five tests is claimed.
