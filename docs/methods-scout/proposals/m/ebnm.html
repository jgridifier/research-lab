  1. Each program gives one noisy number and its standard error.
  2. ebnm estimates how the true values are spread across programs (the prior) from the data itself.
  3. It then shrinks each program toward its group by an amount that depends on how noisy it is.
  4. It returns a better estimate, an interval and the lfsr: the chance you have the direction wrong.
  5. Fast: 0.003–0.6 s per fit on 1,000–1,700 programs.

Formulas and full tables: the 2026-11-13 edition.

Not graded (edition predates grading)

  • Grading started on 11-16, so this edition has no grade. What the page records:
  • Peer-reviewed: Willwerscheid, Carbonetto & Stephens, Journal of Statistical Software 114(3), 2025.
  • Maintained CRAN package (ebnm 1.1-42, 2025-10) from the Stephens lab; the default prior comes from Stephens (2017, Biostatistics).
  • Checked here: 90% intervals covered 89.5% of true levels; lfsr was calibrated (11–13% wrong at 0.05–0.2).
