  1. Draw each series into its own picture.
  2. In each column, divide that series' ink by how many pixels it covers, so a steep noisy line does not paint more.
  3. Add all the pictures: every column now holds exactly n units. Ridges are trends; faint strands are outliers.
  4. No parameters beyond canvas size.
  5. Our NumPy port matches the authors' Rust pixel for pixel (≤ 2.1e-7) but is 10–120× slower.

Formulas and full tables: the 2026-11-13 edition.

Not graded (edition predates grading)

  • Grading started on 11-16, so this edition has no grade. What the page records:
  • Source: Moritz & Fisher (2018), arXiv:1808.06019 (cs.HC), with the first author's own Rust and WebGL implementations.
  • Checked here: exact parity with the reference; a NaN bug in the reference on partial series.
  • At our 5–6 points per line the normalisation barely matters (noisiest 10% take 12.0% vs 10.7% of ink). The paper's gain is for long, high-frequency series.
