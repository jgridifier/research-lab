  • Lineage: seriation goes back to Petrie (1899), dating graves by pottery. The event model, Porčić's test and the EPPM plot are the methods implemented in kairos, with references taken from its reference list.
  • Implementation: kairos (CRAN 2.3.0; its site lists 2.4.0), doi:10.5281/zenodo.5653896, and tabula 3.3.2, peer-reviewed in JOSS (doi:10.21105/joss.01821). Installed from CRAN on 2026-11-15.
  • Discovery: found via the package site and the JOSS paper; not found via X or SSRN.
  • Known limit in the home field: the event model treats deposits as independent and the type list as fixed; both assumptions fail on our data (see On our data).
