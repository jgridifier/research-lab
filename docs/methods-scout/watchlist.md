# Methods scout: watchlist

One row per method or package seen by the daily scout. Status: `trialed` (run on our data, with an edition link),
`watch` (worth a run later), `skip` (reason given). Newest first within each date.

| ecotraj | R (CRAN) | https://cran.r-project.org/package=ecotraj | 2026-11-12 | trialed: recommend for promote workflow | Q1, scheduled exotic run (catch-up published 2026-11-13). Ecological trajectory analysis (De Cáceres et al., Ecological Monographs 89:e01350, 2019; Sturbois et al., Ecological Modelling 440:109400, 2021; v1.2.2; niche). Residual clr increments on 14-dealer trading assets are directional (dir 0.595, sign-flip p = 0.008). Equity-revenue overall directionality fails a sign-flip null (p = 0.664) even though residual net is a GS→JPM swap. Found via Ecological Monographs / ecotraj docs, 2026-11-12. [Edition](2026-11-12.html) |
| lphom | R (CRAN) | https://cran.r-project.org/package=lphom | 2026-11-12 | trialed: interesting | Q1, scheduled exotic run (catch-up published 2026-11-13). On consecutive quarters the matrix is not identified (median bound width 0.88); a planted 1% GS→JPM flow is not recovered. tslphom/nslphom (same paper) are the estimators to retry on Form ADV units. Found via SMR / CRAN, 2026-11-12. [Edition](2026-11-12.html) |

Found via MEE / CRAN / NCEAS, 2026-11-12. [Edition](2026-11-12-adhoc.html) |

Found via PLOS Comp Bio, 2026-11-12. [Edition](2026-11-12-adhoc.html) |
