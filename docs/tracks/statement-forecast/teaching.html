Non-embedding Forecasting of Financial Statements

1. Why this review

Valuation, credit, and stress testing need joint paths for many statement lines over multi-quarter horizons — not only next-quarter EPS. The application panel is bank holding companies on FR Y-9C (preferred: FFIEC NIC BHCF bulk zips), with cheap Yahoo Finance quarterly smoke for tickers in the reporting hierarchy.

Forma-class transformers are a useful contrast (complete statements, identities, 1–20Q), but this note prioritizes transparent, testable, non-embedding methods that can move Yahoo → Y-9C without gated fine-tuned weights.

2. What the lit finds

  • Web Most academic work forecasts one item (earnings) cross-sectionally (Hou–van Dijk–Zhang; Li–Mohanram) or with trees (Chen–Cho–Dou–Lev).
  • Web Full-statement non-transformer systems exist mainly as chained GBM (Geertsema–Lu–Ma) and multitask nets (Alberg–Lipton).
  • Web Bank-native gold: Liu–Moon–Schorfheide empirical-Bayes dynamic panels on Y-9C PPNR under macro scenarios.
  • Web Mixed-frequency (Ball–Ghysels MIDAS; Babii et al. sg-LASSO MIDAS) connects Yahoo daily smoke to quarterly statements.
  • Web Accounting identities are linear constraints — MinT / Girolimetto–Di Fonzo reconciliation is the coherence layer.
  • NIM Recommended stack: EB panel → chained GBM → reconciliation, with MIDAS for smoke and multitask FFNN as neural baseline; park Forma FT.

3. Core method families

A. Empirical-Bayes dynamic panel

Each BHC \(i\) has coefficients \(\theta_i\) in a short dynamic regression (lags + macros). Pooling ignores heterogeneity; firm-by-firm OLS is noisy. EB / Tweedie maps the noisy \(\hat\theta_i\) toward the cross-sectional prior:

\(\mathbb{E}[\theta_i \mid \hat\theta_i] \approx \hat\theta_i + \Sigma \nabla \log m(\hat\theta_i)\)

Forecasts integrate posterior predictive draws — natural for stress scenarios on Y-9C PPNR (Liu–Moon–Schorfheide).

B. Chained multi-output GBM

Predict line items in an order that mirrors articulation (e.g. revenue → expenses → NI → RE → equity → assets). Upstream predictions become features for downstream models. Approximates identities softly; pair with hard reconciliation.

C. MIDAS / sg-LASSO MIDAS

Quarterly target \(y_{t+h}\) on high-frequency \(x\) with parsimonious lag weights \(w(k;\beta)\). sg-LASSO selects groups of mixed-freq predictors across a panel of firms — Yahoo daily → Y-9C quarterly.

D. Forecast reconciliation

Base forecasts \(\tilde{y}\) projected onto \(\{y : Cy = 0\}\) (or \(Cy = c\)):

\(\hat{y} = \tilde{y} - W C^\top (C W C^\top)^{-1} C\tilde{y}\)

MinT chooses \(W\) from forecast-error covariances; Girolimetto–Di Fonzo covers general linear constraints and probabilistic versions. Use predictive variances — equal-weight projection can wreck small lines.

E. Quantiles / multitask nets

Quantile regressions build earnings / PPNR distributions (Konstantinidi–Pope). Small multitask FFNNs share strength across MDRMs without foundation-model fine-tuning (Alberg–Lipton).

5. How to evaluate

  • Point: rolling-origin RMSE / MAE on change-space (or asinh-scaled) PPNR and core MDRMs; Diebold–Mariano across calendar quarters.
  • Probabilistic: CRPS, PIT, interval coverage (nominal 50/90).
  • Coherence: median |identity residual| / gross scale pre vs post reconciliation; never celebrate equal-weight projection alone.
  • Smoke gate: MIDAS Yahoo→PPNR must beat seasonal random walk before bulk EB/GBM spend.
  • No transfer claims: do not quote Forma Compustat R² as Y-9C performance.
